# GPS Tracker

A GPS tracking prototype combining a browser client, a Node.js proxy and a database schema for location data.

## Components
- `index.html` — browser interface
- `tracker-payload.js` — client-side location collection logic
- `proxy-server.js` — server/proxy layer
- `generate-keys.js` — key-generation utility
- `schema.sql` — database schema
- `firebase-rules.json` — example Firebase rules

## Tech Stack
- HTML5
- JavaScript / Node.js
- WebSocket
- Firebase
- PostgreSQL/TimescaleDB

## Privacy & Safety
Use only with informed consent and on devices or systems you are authorized to monitor. Location data is sensitive personal information and should be protected with strong access controls, encryption, retention policies and secure deployment practices.
